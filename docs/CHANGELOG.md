## v0.2 — апрель 2026

**Первая формальная ревизия. Переход от набора идей к специфицированной системе.**

### Спецификация

- Исправлена `NoisyFloat.__mul__`: формула `σ_z = √(b²·σ_a² + a²·σ_b²)` корректна для нулевых значений (старая формула давала деление на ноль).
- Добавлены `__sub__` и `__truediv__` для NoisyFloat с корректным error propagation.
- Добавлена защита `dt <= 0` в `FluxVar.update()`.
- Добавлен `decay_rate` в `SurvivalState` для моделирования затухания угрозы.
- Заменён `print()` на callback `on_trauma` в FluxVar (убран побочный эффект из модели данных).
- Добавлен callback `on_panic` в SurvivalState.
- Добавлен Coupling Protocol (§4.2): формальное описание оркестрации трёх осей.
- Добавлена Event Model (§4.3): сигнатуры callbacks, семантика, паттерн эскалации.
- Mermaid-диаграмма взаимодействия осей.
- Терминология унифицирована (momentum, dispersion, NoisyFlow). Приложение A расширено.

### Документация

- Добавлено: описание парадигмы (Paradigm) для разработчиков.
- Добавлено: сравнение со смежными парадигмами (Related Paradigms).
- Добавлено: четыре проработанных сценария применения (Use Cases).
- Добавлено: Design Rationale (15 обоснованных решений).
- Добавлено: Formal Invariants (инварианты, свойства операций, тестовые спецификации).
- Добавлено: One-pager (elevator pitch).
- Добавлено: Anti-patterns (типичные ошибки).
- Добавлено: Glossary (reference card).
- Добавлено: CONTRIBUTING.md, LICENSE (Apache 2.0).
- Убраны маркетинговые утверждения без доказательной базы («100× быстрее GPU»).
- Убраны все редакционные маркеры (`НОВОЕ:`, `<!-- из файла: ... -->`).

### Манифест

- Полностью переписан: убраны дублирующиеся секции, интегрирован контент из заметок.
- Тон сохранён острым, но убраны формулировки, отсекающие потенциальных союзников.
