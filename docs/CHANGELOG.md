## Unreleased

**Python-библиотека становится носителем парадигмы.**

- Решения по открытым вопросам: confidence остаётся `min()`; в `FluxVar` нет слоя `constraints`; `FlowingTrit` — непрерывный float (`-0.5` допустим, диапазон не клампится).
- `FlowingTrit` и `FluxVar.flow()` (Python-форма оператора `~>`) добавлены в пакет `transflux`.
- `TransfluxSystem` хранит последнее `NoisyFloat` и считает циклы; panic по-прежнему уводит state в `fallback`.
- DSL / LUMEN, Rust, бенчмарки, нейроморфное железо и дальний исследовательский бэклог отложены. Синтетические сценарии — текущая проверка концепции.
- Обоснования: DR-016…DR-019. Журнал решений: `docs/TRANSFLUX_Open_Questions.md`.
- Десять синтетических сценариев в `tests/synthetic/`: палата, дрон, воздух, трит, затухание угрозы. Графики — `docs/figures/synthetic/`.
- `weighted_mean`: среднее независимых измерений с весом `1/σ²`. Confidence следует за весом, а не за `min` (DR-020). Сбойный датчик больше не задаёт городской индекс.
- Запасной режим оркестратора: после panic система держится `backup_value` и `backup_noisy`, если эта пара задана заранее. `recover()` возвращает её ко входу. Без пары panic не залипает (DR-021).
- `classify_jump`: скачок одного датчика (`alone`) отличается от скачка вместе с соседями (`shared`). Confidence и значение при этом не меняются (DR-022).
- `PolyphonicIdentity`: несколько масок одной сущности. `erase` и `rotate_all` убирают старый хеш из всех ссылок книги. Panic делает это только если callback сам вызвал ротацию (DR-023).
- Дорожная карта, журнал решений, статус в README, спецификации §7–§8, one-pager, истории и сценариях применения приведены к составу библиотеки на октябрь 2026.

## v0.2 — апрель 2026

**Первая формальная ревизия. Переход от набора идей к специфицированной системе.**

### Спецификация

- Исправлена `NoisyFloat.__mul__`: формула `σ_z = √(b²·σ_a² + a²·σ_b²)` корректна для нулевых значений (старая формула давала деление на ноль).
- Добавлены `__sub__` и `__truediv__` для NoisyFloat с корректным error propagation.
- Добавлена защита `dt <= 0` в `FluxVar.update()`.
- Добавлен `decay_rate` в `SurvivalState` для моделирования затухания угрозы.
- Заменён `print()` на callback `on_trauma` в FluxVar (убран побочный эффект из модели данных).
- Добавлен callback `on_panic` в SurvivalState.
- Добавлен Coupling Protocol (§4.2): формальное описание оркестрации трёх осей.
- Добавлена Event Model (§4.3): сигнатуры callbacks, семантика, паттерн эскалации.
- Mermaid-диаграмма взаимодействия осей.
- Терминология унифицирована (momentum, dispersion, NoisyFlow). Приложение A расширено.

### Документация

- Добавлено: описание парадигмы (Paradigm) для разработчиков.
- Добавлено: сравнение со смежными парадигмами (Related Paradigms).
- Добавлено: четыре проработанных сценария применения (Use Cases).
- Добавлено: Design Rationale (15 обоснованных решений).
- Добавлено: Formal Invariants (инварианты, свойства операций, тестовые спецификации).
- Добавлено: One-pager (elevator pitch).
- Добавлено: Anti-patterns (типичные ошибки).
- Добавлено: Glossary (reference card).
- Добавлено: CONTRIBUTING.md, LICENSE (Apache 2.0).
- Убраны маркетинговые утверждения без доказательной базы («100× быстрее GPU»).
- Убраны все редакционные маркеры (`НОВОЕ:`, `<!-- из файла: ... -->`).

### Манифест

- Полностью переписан: убраны дублирующиеся секции, интегрирован контент из заметок.
- Тон сохранён острым, но убраны формулировки, отсекающие потенциальных союзников.
